# Glossary

- **Source**: an identifiable document, recording, or supplied transcript with a passage locator.
- **Supported claim**: a narrow statement justified by an inspected passage; not necessarily proof that the speaker's belief was correct.
- **Principle card**: a supported claim paired with a clearly labeled operational interpretation and limits.
- **Project evidence**: observations about the current task, such as repository behavior, user research, measurements, or explicitly identified user reports.
- **Assumption**: a consequential premise not established by available evidence.
- **Synthesis**: a rule or recommendation we construct from sources and project evidence, attributed to this system rather than to either founder.
- **Decision record**: the outcome, evidence, alternatives, reasoning, uncertainty, and validation for a material decision.
- **Independent evidence**: support that does not merely repeat or derive from the same underlying statement or event.
